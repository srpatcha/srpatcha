## ⚡ About Me

I'm an **Embedded Systems Architect** with **12+ years** of experience building everything from bare-metal firmware to full operating systems. I founded [**embeddedos-org**](https://github.com/embeddedos-org) to build **EoS** — a complete embedded operating system platform from scratch.

**What I do:**
- 🔩 Design & build **embedded operating systems**, bootloaders, and firmware
- 🧠 Architect **BSP/Yocto** based Linux distributions for custom hardware
- 🛡️ Implement **BIOS/UEFI**, secure boot chains, and OTA update systems
- 📡 Build **IoT/Matter** connected device ecosystems
- 🤖 Integrate **Edge AI / TinyML** on microcontrollers
- 🏗️ Develop **device drivers**, kernel modules, and real-time systems

**Education:**
- 🎓 M.S. in Information Technology Management
- 🎓 B.S. in Electronics & Communication Engineering
